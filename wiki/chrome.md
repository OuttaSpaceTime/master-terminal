# Chrome

## Tabs

| Shortcut | Action |
|---|---|
| Ctrl + Tab | Next tab |
| Ctrl + Shift + Tab | Previous tab |
| Ctrl + 1 through Ctrl + 8 | Jump to tab 1 through 8 |
| Ctrl + 9 | Jump to the rightmost tab |
| Ctrl + Shift + A | Open Tab Search |
| Ctrl + T | New tab |
| Ctrl + Shift + T | Reopen the last closed tab |

## Side Panel

| Shortcut | Action |
|---|---|
| No default hotkey | Close the Chrome side panel with the X in its top right corner |

## Notes

- Chrome does not document a default hotkey to collapse or expand the side panel.
- Chrome documents `Ctrl + Shift + A` for Tab Search on Windows/Linux and ChromeOS.
- I could not verify `Ctrl + Shift + H` as a default Chrome shortcut on Windows/Linux; Chrome documents `Ctrl + H` for History and `Cmd + Shift + H` on Mac for Home page.
- Chrome's built-in side panel / Tab Search button does not appear to expose a user-configurable hotkey.
- If a vertical-tabs button comes from an extension, the extension can bind a shortcut with `chrome.commands`, and you can remap it at `chrome://extensions/shortcuts`.
- If you meant a tab group, click the group name or colored circle to collapse or expand it.
- Tab groups can also be toggled with `Space` or `Enter` after focusing the group header.
